# Расширение гостевой памяти RV32I

Решение: увеличить гостевую память по умолчанию с 64 до 512 КиБ,
сохранив пространство 2 МиБ и формат копирований 23/24/24 бита.
Поддержать выбор 64, 128, 256 или 512 КиБ при генерации и сборке C.
Гостевая память начинается с прежнего битового адреса 8388608.
Загрузчик перенести за 512 КиБ гостевой памяти; его константы — с
битового адреса 12582912, таблицы — с 12845056, слои — с 13107200.
Заголовок оставить по битовому адресу 15728640.

Ширина гостевого адреса выводится из объёма памяти (16..19 бит).
Проверки чтения инструкций, загрузок/записей и ECALL учитывают этот объём.
Длина канального копирования включает дополнительный бит для передачи
всей памяти одним запросом. Начальный стек по умолчанию — размер памяти
минус 16 байт. Проверки выполняются копированиями внутри пространства;
ядро эмулятора не получает операций RV32I.

Сборка C и генераторы принимают `--memory-bytes`; объём и начальный стек
фиксируются в описании образа. Заголовок потока сохраняет формат RVS1:
выбранный размер уже заложен в передаваемые код RV32I и загрузчик.
Старые готовые образы пространства сохраняют собственные проверки 64 КиБ.

Проверки: независимое сравнение регистров и всей гостевой памяти, доступ
выше 65535, последний допустимый байт/слово, выход за верхнюю границу,
переполнение адресов, вход/выход выше 64 КиБ и запрос на всю память,
выполнение инструкции на верхней границе, загрузка большого потока,
C-программа с данными выше 64 КиБ и стеком у новой верхней границы.
Для вычислений сохранять сырые журналы, IN/OUT и дампы.

Реализовано и проверено: `make test` включает 36 выполнений для 64, 128,
256 и 512 КиБ. `make test-rv32i-c` включает прежние проверки загрузки и
четыре исполнения большого C-образа при O0/O2 через исходный образ и IN.
У C-образа O2 машинная программа занимает 70568 байт, статический массив
в нулевой области данных — 262144 байта. Код читает и выводит данные
выше 64 КиБ и обращается к локальной переменной у конца памяти. Вывод
во всех четырёх вариантах — `XABCDE` при входе `D`.
Артефакты: `tmp/space-tests/rv32i-memory`.

Пример выбора объёма памяти:

```sh
python3 scripts/rv32i/build.py examples/rv32i/sum.c --stream --memory-bytes 524288 -o tmp/sum.stream
printf '1 2\n' | python3 scripts/rv32i/run.py --stream tmp/sum.stream
```

## Предлагаемый интерпретатор

Для первого переноса рекомендуется [pForth](https://github.com/philburk/pforth):
интерпретатор Forth на C. В проекте предусмотрены варианты без файлового
ввода-вывода и malloc, а ввод-вывод отделён от основной реализации.
Нужно заменить операции терминала на cs_read/cs_write, выделить статические
области словаря и стеков, отключить ненужные зависимости и собрать под RV32I.
Для первого варианта использовать 32-битные целочисленные значения и
встроенный словарь, подготовленный для little-endian; отключить поддержку
чисел с плавающей точкой. Первые проверки: `1 2 + .` и определение/вызов
собственного слова, затем циклы и доступ к памяти.
Перенос реализован: pForth собирается под RV32I, загружается через IN
и выполняет пользовательские определения внутри пространства. Команды
запуска, состав словаря и ограничения описаны в [pforth.md](pforth.md).
Источники: README проекта и [режим PF_EMBEDDED](https://github.com/philburk/pforth/blob/master/csrc/pf_all.h).
