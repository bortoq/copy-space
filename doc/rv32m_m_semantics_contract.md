# RV32M Semantics Contract (Risk-1 Mitigation)

Status: active.
Date: 2026-06-01.
Scope: `M` extension semantics only (`mul*`, `div*`, `rem*`).

## Width and interpretation

- Register width: 32-bit.
- Unsigned domain: `u32`.
- Signed domain: `s32` (two's complement).
- All results are written as 32-bit values.

## Multiplication

- `mul`: low 32 bits of signed×signed product.
- `mulh`: high 32 bits of signed×signed 64-bit product.
- `mulhu`: high 32 bits of unsigned×unsigned 64-bit product.
- `mulhsu`: high 32 bits of signed×unsigned 64-bit product.

## Division / Remainder

- `div` (signed):
  - if divisor == 0: result = `0xFFFFFFFF`.
  - if dividend == `INT_MIN` and divisor == -1: result = `INT_MIN`.
  - else: trunc toward zero.
- `divu` (unsigned):
  - if divisor == 0: result = `0xFFFFFFFF`.
  - else: standard unsigned division.
- `rem` (signed):
  - if divisor == 0: result = dividend.
  - if dividend == `INT_MIN` and divisor == -1: result = 0.
  - else: remainder with sign of dividend.
- `remu` (unsigned):
  - if divisor == 0: result = dividend.
  - else: standard unsigned remainder.

TDD gate:
