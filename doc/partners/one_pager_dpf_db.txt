title: Deterministic Data Movement Fabric (DB/Analytics) — Quick Demo

WHAT THIS IS
Copy-Space / DPF is a minimal deterministic execution model focused on data movement.
The core operation is a scheduled copy:
  copy n bits from src to dst
executed in cycles (“ticks”), with explicit scheduling and measurable throughput.

WHY DB/ANALYTICS TEAMS MAY CARE
Many pipelines are dominated by moving bytes, not computing:
- compaction after filter (selection vectors)
- reorder / partition (hash partitioning, sort preparation, materialization)
- bulk buffer movement (DMA-like)

QUICK DEMO (ONE COMMAND, PRODUCES CSV)
Build and run:
  make bins
  scripts/demo_db.sh > /dev/null 2> tmp/demo.stderr
  cat tmp/demo.csv

tmp/demo.csv contains 3 rows:
- pack     (compaction-like)
- permute  (reorder-like)
- bulkcopy (bulk movement)

WHAT TO LOOK AT IN THE CSV
Main metric:
  vmrep_avg_bits_uniq_dst_per_tick
Meaning:
  effective unique destination bits written per tick (ignores overlapping writes)

Expected contrast in default demo:
- pack/permute: ~32768 bits/tick  = 4096 bytes/tick
- bulkcopy:     ~524288 bits/tick = 65536 bytes/tick (64KB/tick)
