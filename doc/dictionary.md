# Термины реализации RV32I

- **Диапазон GNU-инициализатора** — выбор всех элементов массива от первого
  постоянного индекса до последнего включительно; значение вычисляется
  один раз и используется для всего диапазона.

- **Происхождение указателя** — сведения компилятора об адресе объявленного
  объекта и постоянном смещении в нём. Для кадра это виртуальный адрес,
  а не постоянное значение указателя C; сведения нужны для обхода
  подобъектов и выбора членов union при инициализации.

- **Назначенный инициализатор C** — элемент инициализатора с указанием
  конкретного поля (.имя) или элемента массива ([постоянный индекс]).

- **Связывание имени C** — правило, определяющее, обозначает ли имя один
  объект или функцию внутри единицы компиляции (внутреннее связывание)
  либо также в других единицах (внешнее связывание).

- **Глобальный объект C** — объект с именем уровня файла и статическим
  временем жизни, расположенный в загружаемом образе прямых копирований.

- **Предварительное определение C** — объявление объекта уровня файла без
  инициализатора и без extern; при отсутствии последующего определения
  оно задаёт объект с нулевым начальным значением.

- **Строковый литерал C** — массив char со статическим временем жизни,
  полученный декодированием байтов между двойными кавычками, объединением
  соседних литералов и добавлением завершающего нулевого байта.

- **Символьный литерал C** — целочисленная константа из байтов между
  одинарными кавычками с декодированием escape в компиляторе.

- **Перечисление C** — отдельный тип enum с именованными целочисленными
  константами и совместимым целым типом, выбранным по диапазону значений.

- **Смещение поля** — число логических байтов C от начала структуры
  или объединения до выбранного поля, включая индексы вложенных массивов.
- **Статическое утверждение C** — проверяемое при компиляции постоянное
  условие `_Static_assert`; ложное условие запрещает выпуск пакета результата.
- **Выбор по типу C** — выражение `_Generic`, выбирающее одно выражение
  по типу управляющего операнда; управляющий операнд не исполняется.

- **GNU C11** — диалект C11 с расширениями GNU, применяемый Linux 6.12.
- **Препроцессор C** — обработка исходных файлов перед разбором C:
  соединение физических строк, включение файлов, раскрытие макросов и
  условная компиляция. В проекте эта обработка выполняется внутри пространства.
- **Токен препроцессора C** — единица исходного текста до разбора языка C:
  имя, предварительное число, строковый или символьный литерал, знак операции.
- **Объектный макрос C** — имя, определённое директивой #define без списка
  параметров; при использовании заменяется последовательностью токенов.
- **ABI копирований** — договор о размещении данных, передаче параметров,
  адресах объектов и возврате между функциями, исполняемыми копированиями.
- **Кадр вызова** — область локальных данных одного активного вызова функции.
- **Указатель кадра** — битовый адрес текущего кадра вызова в пространстве.
- **Порт Linux для пространства** — архитектурные части Linux, необходимые
  для непосредственного исполнения ядра копированиями, без RV32.

- **Компилятор C → копирования** — программа на pForth, преобразующая
  описанное в `doc/copy_c.md` подмножество C в пакет слоёв копирований.
- **Пакет результата компиляции** — установочная запись стандартного IN
  и двоичные данные с исполняемыми слоями копирований.

- **Хостовый C-runtime** — выполняемые на хосте реализация примитивного
  такта пространства, файловых каналов и программа запуска из `src`.
- **Гостевой C-runtime** — поддержка запуска C, памяти и IN/OUT из
  `runtime/rv32i`, скомпилированная в гостевую программу RV32I.
- **Вложенный эмулятор пространства** — гостевая программа RV32I,
  выполняющая модель пространства над отдельным массивом битов в
  гостевой памяти внешнего пространства.

- **Задание из файла IN** — готовая последовательность загрузки RV32I,
  интерпретатора и пользовательского текста для прямого запуска пространства.
- **Завершающая запись OUT** — последняя запись, сформированная внутри
  пространства и сообщающая этап и результат завершения задания;
  формат определён в `doc/file_job.md`.

- **pForth** — переносимая реализация Forth на C, исполняемая
  как гостевая программа RV32I.
- **Словарь pForth** — имена слов, их код и данные в гостевой памяти;
  встроенный словарь загружается с программой, новые слова создаются
  интерпретатором при исполнении пространства.

- **Установочная запись загрузчика** — проверяемая стандартным core запись
  IN, устанавливающая до 48 бит загрузчика в пространство.
- **Заголовок гостевой программы** — подпись RVS1, длина и entry, прочитанные
  загрузчиком перед байтами программы RV32I.

- **RV32I** — базовый набор 32-битных целочисленных инструкций RISC-V.
- **Гостевая память** — область пространства для байтов программы RV32I и её данных;
  гостевые адреса измеряются в байтах и преобразуются в битовые адреса пространства.
- **Регистр RV32I** — 32 бита состояния программы в пространстве; `x0` всегда нулевой.
- **pc** — гостевой адрес исполняемой инструкции.
- **Генератор образа RV32I** — внешняя программа, создающая постоянные таблицы,
  слои копирований и начальное состояние. При исполнении образа генератор не участвует.
- **Контрольный кадр** — копия регистров, pc и причины остановки в OUT после
  инструкции; используется для независимой проверки исполнения.
- **Исключение RV32I** — остановка образа с причиной ошибки и сохранением pc
  инструкции, на которой возникла ошибка.
- **Профиль ввода-вывода RV32I** — вариант образа, в котором ECALL вызывает
  чтение IN, запись OUT или завершение; базовый профиль оставляет ECALL исключением.
- **Код завершения гостевой программы** — 32-битное значение, переданное
  программой C при завершении и сохранённое в пространстве.

## Дополнительные термины целочисленной части C

- **unsigned int** — 32-битное беззнаковое целое в ABI копирований.
- **Обычные арифметические преобразования** — выбор общего типа операндов
  C; для поддерживаемой пары int/unsigned int общим является unsigned int.
- **Короткое замыкание** — правый операнд && или || исполняется только
  если его значение требуется для результата; результат имеет тип int.
- **Условное выражение** — `условие ? значение1 : значение2`; исполняется
  только одна ветвь, а тип результата учитывает обе ветви.
- **lvalue** — выражение C, обозначающее объект. Запись разрешена только
  для изменяемого объекта. Это переменная, элемент массива, поле или
  объект за указателем. Метаданные lvalue существуют в компиляторе;
  чтение и запись объекта исполняются копированиями.
- **rvalue** — значение выражения, не обозначающее объект присваивания.
- **Квалификатор типа C** — const запрещает изменение объекта через
  квалифицированное lvalue; volatile требует сохранения предусмотренных
  обращений к объекту при получении либо отбрасывании скалярного значения.
- **Псевдоним типа C** — имя, введённое typedef для уже разобранного типа;
  не создаёт новый несовместимый тип и следует обычной области видимости имён.
- **Составное присваивание** — операция вида `x += y`, которая вычисляет
  адрес x один раз, выполняет операцию и записывает преобразованный результат.
- **Область видимости блока** — область действия объявленных в блоке имён;
  внутренний блок может скрыть внешнее имя, а повтор имени в одном блоке
  считается ошибкой.
- **Невычисляемый операнд** — выражение, разбираемое для получения типа
  без исполнения его копирований; применяется к sizeof и typeof для
  поддерживаемых типов без переменного размера.
- **GNU-выражение из операторов** — `({ ...; выражение; })`, значение
  последнего выражения которого является результатом всего выражения.
- **Стек возвратов pForth** — стек адресов возврата слов Forth и временных
  данных разбора; отличается от кадров вызовов результирующей C-программы.
- **Описание типа C** — метаданные компилятора о размере, выравнивании,
  знаковости, квалификаторах и связанном типе объекта; не выполняет
  вычисления вместо копирований результата.
- **Логический байт C** — восемь последовательных бит объекта C,
  интерпретируемые числом от 0 до 255. Порядок этих битов в физическом
  байте пространства может отличаться от байта файлового канала;
  преобразование при вводе/выводе выполняется внутри пространства.
- **zstd-журнал** — полный сырой журнал событий, сжатый zstd без потерь;
  при распаковке сохраняется каждый исходный байт, включая порядок событий.
- **Размещение RV32I** — выбранный размер пространства и выведенные из него
  ширины полей копирования, размер слоя и границы гостевой памяти и загрузчика.
  Используется при подготовке образа; выполнение RV32I остаётся копированиями.

- **Switch C** — выбор места начала исполнения тела по однократно
  вычисленному целому управляющему выражению после его продвижений.
- **Метка case** — место в теле switch, выбираемое по постоянному целому
  значению либо диапазону GNU; default выбирается при отсутствии совпадения.
  После выбранной метки исполнение продолжается последовательно до перехода.

- **Метка перехода C** — именованное место начала оператора внутри функции;
  имя действует во всей функции отдельно от имён объектов и типов.
- **Goto C** — переход к именованной метке перехода в той же функции.
- **Описание вложенности GNU-выражения из операторов** — номер выражения
  и номер содержащего его выражения, либо ноль для тела функции;
  позволяет проверить допустимость перехода между такими выражениями.

- **Declarator C** — часть объявления или абстрактного типа, задающая имя,
  указатели, массивы и функции с учётом порядка вложенных скобок.

- **Тип функции C** — описание возвращаемого типа и параметров функции;
  отличается от типа указателя на неё и не обозначает объект данных.
- **Описание прототипа C** — список типов и имён параметров, признак
  наличия прототипа и признак переменного числа параметров; имена нужны
  при разборе объявления, но не определяют совместимость типов функций.

- **Описание функции в ABI копирований** — запись с адресом входа и
  смещениями ячеек кадра для возврата, результата и параметров; адрес
  записи представляет указатель на функцию C в этом ABI.
- **Обозначение функции C** — выражение типа функции; при получении
  значения преобразуется в указатель на функцию, не читая объект данных.

- **Косвенный вызов C** — вызов через вычисленный указатель на функцию;
  в ABI копирований поля описания функции задают переход и размещение
  возврата, результата и параметров в новом кадре.
- **Начальный слой main** — код загрузки результата C, который задаёт
  возврат из main и после него направляет результат в OUT; тело main
  выполняется и возвращается по обычному соглашению вызовов.
- **Область дополнительных аргументов C** — часть кадра функции с `...`,
  содержащая переданные после именованных параметров значения; указатель
  `__builtin_va_list` выбирает следующий элемент этой области.
- **Макрос C с параметрами** — определение #define, в котором сразу после
  имени следует список параметров в скобках; раскрытие заменяет параметры
  токенами аргументов. Многоточие обозначает переменное число аргументов.
- **Запреты раскрытия токена** — набор имён макросов, которые больше
  нельзя раскрывать для данного токена при повторном просмотре результата
  подстановки; предотвращает повторное раскрытие рекурсивных ссылок.
- **Набор файлов C CCFILES1** — вход компилятора с именами файлов,
  неизменёнными байтами их содержимого, индексом главного исходника и
  упорядоченными каталогами поиска заголовков; передаётся через канал IN.
- **Запрос доступности заголовка** — оператор __has_include или
  __has_include_next в условии препроцессора; проверяет поиск имени
  в наборе CCFILES1 без включения и исполнения содержимого файла.
- **Атрибут размещения** — packed или aligned, задающий размещение
  полей и выравнивание определяемой структуры либо объединения.
- **Гибкий массив** — последнее поле T[] непустой структуры;
  его элементы располагаются в дополнительном предоставленном месте
  после префикса, а размер поля не входит в sizeof структуры.
- **План статического размещения** — размеры объектов в порядке
  их выделения, используемые при повторной компиляции для получения
  окончательных адресов до генерации ссылок.
- **Нулевой массив** — GNU-массив T[0] с известной нулевой длиной;
  отличается от неполного T[] и имеет sizeof, равный нулю.
- **Агрегатное значение** — значение структуры или объединения,
  сохранённое во временном объекте кадра; оно не является lvalue.
- **Буфер агрегатных аргументов** — полуинтервал для передачи
  представлений крупных значений перед переключением кадра вызова.
