# Оптимизация копирований

## Назначение

Этот документ задаёт первый вариант оптимизации копирований.

Его цель:

1. уменьшить число копирований;
2. уменьшить число слоёв копирований;
3. уменьшить общее число копируемых битов.

Документ не описывает совершенную оптимизацию.
Он описывает достаточный алгоритм, по которому можно написать рабочий код.

## Вход

Входом оптимизатора является последовательность слоёв копирований.

Каждый слой состоит из инструкций вида:

`copy n, dst, src`

где:

- `n` — число копируемых бит;
- `dst` — индекс позиции назначения;
- `src` — индекс позиции источника.

Также оптимизатор должен знать, какие биты результата считаются нужными после завершения вычисления.

## Выход

Выходом оптимизатора является новая последовательность слоёв копирований, которая:

- сохраняет тот же результат вычисления;
- содержит меньше копирований или не больше прежнего;
- содержит меньше слоёв или не больше прежнего;
- копирует меньше битов или не больше прежнего.

## Представление

Полуинтервалы используются только как форма входа и форма выхода.

Внутренняя рабочая форма оптимизации — отдельные биты.

Для оптимизации каждая инструкция временно раскладывается на побитовые копирования.

Инструкция

`copy n, dst, src`

представляется как набор из `n` битовых копирований:

- `src + 0 -> dst + 0`
- `src + 1 -> dst + 1`
- ...
- `src + n - 1 -> dst + n - 1`

Вся дальнейшая оптимизация выполняется только над этим побитовым представлением.

После оптимизации битовые копирования снова собираются в полуинтервалы.

## Правила оптимизации

### 1. Удаление лишних копирований

Если значение бита записано, но затем до любого его чтения перезаписано, такое копирование лишнее.

Тогда:

- соответствующее битовое копирование удаляется;
- если после этого инструкция перестаёт содержать нужные битовые копирования, инструкция удаляется;
- если у инструкции остаётся только часть полезных битов, инструкция укорачивается или разбивается на несколько полуинтервалов.

### 2. Удаление лишних слоёв

После удаления лишних копирований оставшиеся копирования нужно перепланировать по слоям.

Копирование может быть перемещено в более ранний слой, если:

- к моменту выполнения уже определены все читаемые им биты;
- его запись не разрушает значения, которые ещё должны быть прочитаны;
- оно не нарушает принятые ограничения на совместимость копирований внутри одного слоя.

Цель перепланирования — поместить каждое копирование в как можно более ранний слой.

### 3. Слияние смежных копирований

После перепланирования побитовые копирования нужно снова собирать в полуинтервалы.

Два соседних копирования можно слить, если:

- они находятся в одном слое;
- они читают соседние биты источника;
- они пишут соседние биты назначения;
- порядок соответствия битов сохраняется.

Тогда вместо двух копирований создаётся одно копирование большей длины.

## Общий порядок работы

Оптимизатор выполняет следующие шаги.

1. Разложить все копирования до уровня отдельных битов.
2. Отметить биты, которые нужны в результате.
3. Обратным проходом удалить все лишние битовые копирования.
4. Удалить пустые инструкции.
5. Перепланировать оставшиеся копирования по как можно более ранним слоям.
6. Собрать смежные битовые копирования обратно в полуинтервалы.
7. Повторять шаги `2-6`, пока результат ещё меняется.

## Требования к реализации

Реализация должна:

- работать детерминированно;
- при одинаковом входе всегда давать одинаковый выход;
- не изменять смысл вычисления;
- не вводить новые копирования без необходимости;
- уметь удалять инструкцию целиком;
- уметь укорачивать инструкцию;
- уметь разбивать инструкцию на несколько полуинтервалов;
- уметь собирать несколько битовых копирований обратно в один полуинтервал.

## Внутренние структуры

Для реализации достаточно следующих структур.

### Побитовое копирование

Для каждого бита:

- номер слоя;
- индекс источника;
- индекс назначения;
- ссылка на исходную инструкцию;
- флаг "нужен / не нужен".

### Полуинтервал

Для каждой инструкции:

- номер слоя;
- начальный индекс источника;
- начальный индекс назначения;
- длина;

### Результат

После обратной сборки:

- список слоёв;
- внутри слоя список инструкций `copy n, dst, src`.

## Минимальный интерфейс кода

По этому документу можно писать код, если реализовать следующие шаги как отдельные функции:

1. разбор слоёв копирований;
2. раскладка полуинтервалов в биты;
3. удаление лишних побитовых копирований;
4. перепланирование по слоям;
5. слияние смежных битов в полуинтервалы;
6. повторение до неподвижной точки.

## Ограничение этого варианта

Этот документ не описывает:

- совершенную глобальную перестановку битов;
- совершенную глобальную оптимизацию всей схемы сразу;
- оптимизацию специального канального протокола;
- оптимизацию межмодульного взаимодействия.

Он описывает только первый достаточный вариант оптимизации:

- удалить лишнее;
- уменьшить число слоёв;
- слить смежное.
