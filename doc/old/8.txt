todo B: pointers (block pointers) — завершено вертикальным срезом
Принятые решения
Используются только block pointers: bitaddr % 32 == 0, 24-bit значение лежит в [base..base+23] внутри 32-bit блока.
Raw bit pointers отложены.
ABI дальше стараемся не расширять, но уже добавлены ART[67..69] (см. ниже).
Реализовано
Добавлены 3 слова-примитива (mkimage/std7_fixed):
WORD_LOAD24AP (читает 24 бита из *AP в VAR_A24)
WORD_LOAD24BP (читает 24 бита из *BP в VAR_B24)
WORD_STORE24RP (пишет 24 бита из VAR_SUM24 в *RP)
Файл: src/mkimage/std7_fixed/words_loadstore24p.c
Подключение: в src/mkimage/std7_fixed/legacy.c (адреса words pages 26..28 + вызовы builder’ов).
ART расширен append-only:
ART[67] = WORD_LOAD24AP
ART[68] = WORD_LOAD24BP
ART[69] = WORD_STORE24RP
ART_COUNT = 70
Файлы:

src/mkimage/std7_fixed/addrs.h (добавлены поля word_load24ap/bp/store24rp)
src/mkimage/std7_fixed/artifacts.h (enum + ART_COUNT=70)
src/mkimage/std7_fixed/artifacts.c (writer дописан; также он теперь пишет ART[65..66])
Token-tests добавлены и PASS:
src/tokens/mktok_test_add24p_via_prims.c — add по указателям + store по RP, результаты в layout как mktok_test_add24.c.
src/tokens/mktok_test_lt24p_via_prims.c — lt по указателям, вывод 4 байта (0x80 true).
Pointer arithmetic реализована “как макросы” внутри этих тестов: AP/BP/RP += 32 через существующие слова (без новых слов/ABI).
