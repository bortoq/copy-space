# Словарь терминов

Этот документ задает термины, которые используются в активной документации проекта.

## Основные термины

- `host` - аппаратная и ОС-среда, в которой запускается проект; это не отдельный слой целевой архитектуры.
- `vmrun` - legacy bootstrap helper, выведенный из active path после появления `src/tools/space.c`.
- `space.*` - эмулятор адресного пространства. Это не runtime для orchestration и не место для чужой логики.
- `resident` - код или данные, которые живут внутри адресного пространства и исполняются там после bootstrap.
- `bootstrap` - первый запуск пространства и подготовка стартовых данных перед первым тактом.
- `bootstrap-only` - допускается только для запуска, загрузки и bounded dump/diagnostics. Не является активным execution layer.
- `boundary` - документированная граница, за которой начинается или заканчивается ответственность компонента.
- `runtime` - минимальный исполняемый цикл, который владеет своим состоянием и своими переходами.
- `orchestration` - выбор, запуск и сопровождение resident-работ после bootstrap.
- `copy scheduling` - выбор и выполнение нужных копирований полуинтервалов.
- `job selection` - выбор следующей resident-задачи по правилу из resident-visible таблицы или состояния.
- `tool invocation` - переход от выбранной задачи к запуску инструмента и обратно к записи о завершении.
- `toolchain control` - управление подготовкой resident-артефактов и control records.
- `ownership` - обязанность компонента самому принимать решение и самому записывать результат в своей области ответственности.
- `launch control` - решение о запуске resident-пути после bootstrap и запись этого решения.
- `completion bookkeeping` - запись факта завершения resident-пути и его результата.
- `tool dispatch` - передача выбранной resident-задачи в нужный инструмент после bootstrap.
- `after bootstrap` - все, что происходит после первого запуска пространства и передачи первого управления resident-пути.
- `proof gate` - проверяемый запуск, который доказывает одно конкретное утверждение.
- `contract` - документ с фиксированным правилом поведения или границей.

## Правило

Если термин не определен здесь, его надо либо заменить на уже определенный, либо добавить в этот словарь.
