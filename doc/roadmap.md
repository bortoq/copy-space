# Roadmap

## Правила

- В этот файл заносятся только задачи реализации проекта.
- Порядок задач должен соответствовать наименее проблематичному порядку реализации.
- Выполненные задачи помечаются `✅`.
- Невыполненные задачи помечаются `❌`.
- Если задача уточняется или дробится, это делается прямо в этом файле.
