# C3 Known Limits (S10 Baseline)

Status: frozen in S10.
Date: 2026-06-01.

## Scope limits

- C3 focuses on narrow RV32I slices validated by current truth/diff gates.
- No claim of full architectural completeness outside covered slices.
- Trace artifacts are deterministic for known cases generated by `c3_emit_trace.py`.

## Runtime/diagnostic limits

- `stop_dump.bin` in repro bundle is still placeholder for mismatch path.
- Native runtime artifacts are captured only for wired cases in `c3_run_and_diff.sh`.

## Performance limits

- Budget thresholds are enforced by `test_c3_budget.sh` and per-slice budget tests.
- Baseline and repeat-stability are environment-dependent; gate controls degradation via percentage threshold.

## Process limits

- Any extension beyond frozen set requires: new truth gate + diff gate + budget gate.
- SHA track remains deferred until C3 freeze is kept green and explicit switch is approved.
